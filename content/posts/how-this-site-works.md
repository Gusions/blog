date: 2026-10-18

description: Plain text files, a small build script and a static host. Nothing more.
---

Every post here is a plain Markdown file. A small script turns those files into static pages, and a static host serves them. There is no database and no login.

I like this setup because the files are what matter. The tools around them can change, but a folder of text files stays readable.

Posts can link to each other with simple double-bracket links, and each post automatically lists the others that mention it. You can see that at the bottom of [[Hello, this is Gusions]].

There is also a switch in the header that changes the look between the default theme and a plain black and white one.
