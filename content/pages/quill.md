---
title: Quill
description: Write and publish a GitHub-hosted blog from Obsidian.
---

If your site is a folder of Markdown files on GitHub, Quill brings those files into Obsidian. You write with the editor you already use and publish when you're done. This site is written with it.

New posts start as drafts. If a file changed on GitHub in the meantime, Quill stops and asks before overwriting anything.

> **Private repository.** The code is not public yet. If you would like to try it, [get in touch](/about).
