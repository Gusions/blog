If your site is a folder of Markdown files on GitHub, publishing usually means a code editor, a terminal and a commit. Quill lets you do it from Obsidian instead. This site is written with it.

## What it does

- **Pull.** Quill downloads your posts and pages from the repository into the vault.
- **Write.** You edit with Obsidian's own editor, front matter included.
- **Publish.** When you're done, Quill commits the changes to GitHub, and your host rebuilds the site.
- **Dashboard.** All posts in one table with title, date, topics and status, filters for live posts, drafts and pending changes, and search.

## Safe by default

New posts start as drafts, so nothing goes live by accident. If a file changed on GitHub since your last pull, Quill stops and asks before overwriting it, and keeps a backup of your local version.
