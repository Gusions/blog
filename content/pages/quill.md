---
title: Quill
description: Write and publish this site from Obsidian.
---

This site is a folder of Markdown files on GitHub. Quill brings those files into Obsidian, lets me write with the editor I already use, and publishes the changes when I'm done.

New posts start as drafts. If a file changed on GitHub in the meantime, Quill stops and asks before overwriting anything.

Personal project, not published.
